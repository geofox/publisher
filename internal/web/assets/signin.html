Sign-in isn't set up yet.

Open the setup link from the server's log (or from SETUP_TOKEN_FILE, if you set it), or make a new one in the container:

docker exec publisher /publisher setup-url

Locked out?

On the server, run docker exec publisher /publisher owner reset-login. It removes every passkey and the password, signs everyone out, and prints a new setup link.
